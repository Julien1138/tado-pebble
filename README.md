# Tado pour Pebble

Application Pebble (C + PebbleKit JS) de pilotage Tado depuis la montre.

## Documentation

Sources LaTeX dans `docs/` (les PDF ne sont pas versionnés) :

- `docs/cahier-des-charges/` — spécification des exigences système (TPB-SyRS)
- `docs/conception/` — document de conception logicielle

Compilation : `cd docs/<dossier> && latexmk -pdf <fichier>.tex`
(`cahier-des-charges.tex` ou `conception.tex`).
